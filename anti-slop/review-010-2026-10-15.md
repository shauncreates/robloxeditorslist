# Profile navigation and action styling

Reading this as: a refinement of REL's public profiles, homepage and account navigation for community members. Existing dark green surfaces, original logo and Red Hat Text remain the direction. ENERGY 1 / RHYTHM 1 / MOTION 1. The user requested arrows, account/action icons, smooth feedback and a green gradient close to REL's current lime.

## Block 1: Hard Gate

PASS. Public profile links no longer rely on underlines. Outlined controls, directional arrows and external-link icons identify destinations at rest. Account buttons retain a visible text label alongside the icon; decorative SVGs are hidden from assistive technology. External links retain an announced new-tab description. No destinations, permissions, private data, rankings or application behavior change.

The existing Chromium regression passes the public/account/home/admin flows at 320/390/768/1440px, including long content, empty, missing and retry states. A final visual check confirms no profile underlines, working account navigation, visible keyboard focus, 44px minimum action targets and no horizontal overflow. SVG symbols are served locally and do not depend on an external icon font.

## Block 2: Purpose-Gate

PASS. The account gradient uses lime and adjacent greens to mark the personal-account destination. Secondary actions use quiet dark surfaces and contrasting borders, preserving the identity heading as the focal point. The person icon identifies account access; list, settings and sign-out icons identify their existing actions. Right arrows indicate internal navigation, while diagonal arrows distinguish external destinations. These cues replace underlines without relying on color alone.

Background movement, a two-pixel lift and three-pixel arrow movement acknowledge hover or keyboard focus. They run only on interaction. Reduced-motion mode removes the movement and transitions. Homepage contributor cards now use a small lift in place of scaling, preventing neighboring cards from being covered. No glow, shadow, new typeface, background decoration or visual dependency was added.

## Block 3: Liveliness

PASS. The dials remain consistent with the original profile page. The requested green gradient adds emphasis to a specific action; the existing logo, typography and green link/focus color maintain REL identity. Spacing keeps icons attached to their labels, action groups wrap on narrow screens and the profile's content hierarchy remains intact.

## Block 4: Craftsmanship and quality

PASS. Native anchors preserve link behavior while appearing as buttons. Every new icon accompanies a text label. Keyboard focus has a visible lime ring; forced-colors mode removes the gradient and uses system link/border/focus colors. No fabricated content, new marketing copy or unsupported claims were introduced. Source changes use the normal HTML/CSS/JS files and a small local SVG symbol sheet.

Computed gradient-label contrast is at least 10.28:1 across its three stops. Secondary text on hover surfaces is 15.06:1, lime on hover surfaces 11.84:1 and control borders at least 3.61:1 against adjacent dark surfaces. Text exceeds 4.5:1; non-text boundaries exceed 3:1.

Validation: six existing UI checks, static build, full existing Chromium regression and a final visual/accessibility check for normal/reduced motion and forced colors. Desktop and mobile previews use fictional fixture data, with genuine local fonts because external Google Fonts is blocked here. No production database changes, merge or deployment.
