# Public profiles and contributor links

Reading this as: public member/editor profiles for the REL community, using the existing dark green surfaces, lime accent, Red Hat Text and original SVG. ENERGY 1 / RHYTHM 1 / MOTION 1. The existing site is the visual direction; AREDL supplies the stable identity-linking pattern only.

## Block 1: Hard Gate

PASS. New copy has no em dash, invented statistics, testimonials or marketing claims. The four contributor credits come from the existing homepage; no account ownership is inferred. Initial placeholders are visibly initials, not generated portraits. Public content has loading, missing, unlinked and error/retry states. Public links have real destinations, and Owner forms save through checked APIs with visible saving/success/error messages.

Chromium exercised the new public pages at 320/390/768/1440px, including unranked accounts, editors, unlinked/linked credits, missing profiles and service errors. It checked loaded fonts and document overflow, direct reload, query-preserving redirects, native Enter activation, placement navigation, full-profile links and 200% zoom. Existing drawer Escape behavior remains covered. New controls retain visible lime focus indicators and 44px touch targets. Browser screenshots were reviewed locally under `.wrangler/ui-review/` using fictional data.

## Block 2: Purpose-Gate

PASS. Color and typography preserve REL identity across account, ranking and profile pages. A single identity heading is the focal point. A wide content column carries contributions/about/video, while the narrower column makes placements easy to scan; mobile stacks them, and accounts without descriptive content use one column. Section spacing separates different kinds of information. Thin dividers group content without extra cards. Existing green link/focus color marks actions. No new gradients, glass, shadows, decorative icons, badges or animations were added.

## Block 3: Liveliness

PASS. Dials were declared before implementation. The original REL SVG, type and lime link/focus motif carry identity. Username/name hierarchy makes the person the focal point. The restrained rhythm suits a profile reference page; larger gaps separate identity from details and smaller gaps keep credits and placements together. Motion stays with existing hover/focus feedback. Empty profiles omit absent about/video/links rather than filling a template.

## Block 4: Craftsmanship and quality

PASS. Identity links use stable IDs, not display-name guesses. New public code escapes text, filters unsafe URLs, rejects credentials in URLs and restricts video embeds to actual YouTube hosts. Tests exercise hostile text/links without script execution. Accounts expose only ID and username, plus existing public editor information and credits. Private roles, emails, claims and reviews remain absent. Owner mapping changes are authorized again in SQL and audited; rankings, revisions and account permissions are unchanged.

Computed contrast against the darker REL panel: muted text 7.62:1, lime links/focus 13.61:1, main text 17.32:1. Error text against the page is 11.22:1. The existing control-border color used for the new Owner form is 4.15:1, above the 3:1 non-text threshold. All text pairings exceed 4.5:1. The original SVG is unchanged. No new dependencies or production credentials were added.

Validation: the full isolated test suite, targeted final profile tests, static build, Functions compilation and Chromium regression checks. Both migration orders with the saved application/email branch were tested in disposable PostgreSQL fixtures, preserving ranking JSON and revision tokens. Browser font checks use genuine local font fixtures because external Google Fonts is blocked in this environment; external font delivery is not verified. No hosted migration, merge or deployment was performed.
